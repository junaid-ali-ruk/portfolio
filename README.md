# 🌐 Junaid Ali – Portfolio

This is my personal portfolio website built with **Next.js**, **TailwindCSS**, and modern UI animations using **Framer Motion**.  
It showcases my projects, skills, and ways to connect with me.

---

## ✨ Features
- Responsive design for desktop & mobile
- Smooth animations with Framer Motion
- Dark/Light theme support
- Contact section with email integration
- Clean and minimal UI

---

## 🛠️ Tech Stack
- [Next.js](https://nextjs.org/)
- [React](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [Lucide Icons](https://lucide.dev/)

---

## 🚀 Getting Started

### 1. Clone the repo
```bash
git clone git@github.com:junaid-ali-ruk/portfolio.git
cd portfolio
```
### 2. Install dependencies
```bash
bun install  
```
### 3. Run the development server
```bash
bun dev   
```
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
